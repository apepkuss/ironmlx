        Metrics Reference
      

      

        

          

            
TTFT (Time to First Token)

            
Latency before the model starts responding. Measures prompt processing (prefill) speed. Lower is better.

          

          

            
TPOT (Time per Output Token)

            
Average time between each generated token. Measures decode speed. Lower is better.

          

          

            
tg TPS (Token Generation TPS)

            
Output tokens generated per second. Inverse of TPOT. Higher is better.

          

        

        

          

            
pp TPS (Prompt Processing TPS)

            
Input prompt tokens processed per second during prefill. Higher is better.

          

          

            
End-to-End Latency

            
Total time from request submission to complete response. Includes prefill + generation.

          

          

            
Total Throughput

            
Total tokens processed per second (input + output). Measures overall system utilization.

          

          

            
Batch Size

            
Number of concurrent requests processed simultaneously. Larger batches increase throughput but add per-request latency.

          

          

            
Speedup

            
Token generation throughput multiplier relative to single-request baseline (1x). Higher is better.

          

          

            
pp TPS/req (Per-request Prompt TPS)

            
Prompt processing throughput divided by batch size. Shows per-request prefill speed under batch load.

Memory Limit (Total)
Total memory limit for the server process (model + KV Cache + overhead). Exceeding this triggers LRU model eviction. Set 0 for auto-detect.

Memory Limit (Model Only)
Max memory for loaded models. Set 0 for no limit.

Hot Cache Limit (Memory Cache)
In-memory cache for frequently accessed prefixes. Auto mode estimates a conservative size from system unified memory, capped at 8GB.

        
Auto (8GB)

      

      

        
Cold Cache Limit (SSD Cache)
Maximum disk usage for the SSD Prefix Cache. The upper limit is adjusted from available disk space.

        
10GB

      

      

        
SSD Cache Directory

        

      

      

        
KV Cache Compression
Compress KV cache to reduce memory usage. It cannot be enabled together with Prefix/SSD Cache. Save settings and restart the backend to apply changes.

        

      

    


    
    

      

        
          
          Advanced
        
        restart
      

      

        
Max Sequences
Maximum number of concurrent parallel requests.

        

      

      

        
Max Loaded Models
Maximum number of models kept loaded in GPU memory simultaneously. Exceeding triggers LRU eviction of the least-recently-used non-pinned model. Keep this low (1–2) on 16–32 GB machines.

        

      

      

        
Initial Cache Blocks
Number of pre-allocated KV cache block slots. 0 = auto-calculate from hot cache limit.

        

      

      

        
Model Auto-Unload (TTL)
Automatically unload idle non-pinned models after this many minutes. 0 = disabled.

        
 minutes

          Advanced
        
        restart
      

      

        
Communication Backend
Transport used for inter-node communication. Auto picks jaccl when Thunderbolt Bridge is available, otherwise ring (TCP).

        

          
        

      

      

        
Parallel Mode
How the model is sharded across nodes. Auto picks TP / PP / Hybrid based on topology and head divisibility.

        

          
        

      

      

        
      

    


    
    

      

        
        Requirements
      

      

        

          ①
          All nodes must be Apple Silicon Macs (M1 or later). x86 machines are not supported.
        

        

          ②
          All nodes must load the same model (same HuggingFace repo or local path).
        

        

          ③
          Nodes must be on the same network. Ensure firewall allows ports 9068, 19100, 19101.
        

        

          ④
          Tensor Parallel requires n_kv_heads divisible by node count. Otherwise Pipeline Parallel is used automatically.
        

        

          ⑤
          For best performance, connect nodes via Thunderbolt cable and enable "Thunderbolt Bridge" in macOS System Settings → Network.
