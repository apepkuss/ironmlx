# IronMLX 0.1.0 release candidate notes

Status: **not publicly released**. This version establishes the engineering
and documentation baseline for the first standalone product release, but public
binary distribution remains blocked by the P0-8B legal-material gate.

## Highlights

- Self-contained macOS App and Rust/MLX inference backend for Apple Silicon;
- OpenAI Chat Completions and Anthropic Messages compatible APIs;
- Multi-model lifecycle, resumable downloads, immutable snapshots, and
  integrity verification;
- Continuous batching, paged KV/prefix cache, MTP, Prompt Lookup, and memory
  protection;
- Image input for Gemma4, MiniCPM-V 4.6, and DiffusionGemma;
- Loopback by default, with optional LAN mode using HTTPS, API keys, and
  Keychain credential storage.

## Product baseline

- App, CLI, `healthz`, Cargo workspace, and release metadata use `0.1.0`;
- `VERSION` and bump/consistency-check workflows are established;
- All workspace crates set `publish = false`;
- The App provides a standard About panel;
- Reproducible arm64 Release dependency inventory, notices, and license texts
  are generated and bundled in the App/archives;
- Installation, model, API, privacy, storage/uninstall, troubleshooting, and
  Known Issues documentation is available in English and Simplified Chinese.

## Remaining before release

- Complete legal and attribution review of generated third-party materials;
- Generate and review CycloneDX `SBOM.cdx.json`;
- Complete Developer ID signing, notarization, stapling, and real-model
  acceptance on the minimum target machine.

See [Known Issues](../known-issues.md) for current limitations.
