# IronMLX 0.1.0 release notes

Release candidate: `0.1.0-rc.1`. This build is for testing and feedback, not a stable release. Download availability is determined by the GitHub Releases page.
IronMLX is a local inference App for Apple Silicon with a Dashboard and HTTP APIs for compatible clients.

## System requirements

- Apple Silicon (arm64), macOS 26.4 or later; Intel Macs are not supported.
- Memory needs depend on model size, quantization, context and concurrency. Architecture support does not guarantee that every device can load a checkpoint.

## Supported model architectures

| Model family | Inputs |
| --- | --- |
| Qwen 3.5 Dense; Qwen 3.6 / 3.8 Dense using the same architecture | Text; images with compatible vision configuration and weights |
| Qwen 3.5 / 3.6 MoE | Text; images with compatible vision configuration and weights |
| Gemma 4 / Gemma 4 Unified | Text; images with compatible vision configuration and weights |
| GLM-4 MoE Lite | Text |
| Llama GQA Dense, including compatible MiniCPM5-1B | Text |
| MiniCPM-V 4.6 | Text and images; image input requires compatible vision weights |
| DiffusionGemma | Text and images |

Compatibility can vary between versions and quantized files in the same model family. Check the
[supported model matrix](../supported-models.md) for validated models and feature limitations before downloading.
Multiple quantization formats let you choose a model version that fits your device's memory; see the matrix for supported formats.

## APIs and Agent integration

- OpenAI Chat Completions, stateless Responses and Anthropic Messages compatible APIs, with HTTP/SSE streaming.
- Reasoning output and tool calling support multi-turn Agent tasks where supported by the model. Clients execute tools.
- Structured Outputs and JSON Schema constraints within the [API compatibility matrix](../api-compatibility-matrix.md).
- Hermes Agent and oh-my-pi setup guides help connect local models and link to official configuration instructions.

## Model management and inference optimization

- Unified Dashboard download queue for Hugging Face / ModelScope, resumable downloads, cancellation
  and file integrity verification.
- Load and unload models, choose a default, pin frequently used models, set automatic unload times and save settings.
- Concurrent requests, prompt cache reuse and memory protection, with available optimizations depending on the model and runtime mode.
- MTP or auxiliary models can accelerate generation for compatible Qwen/Gemma models. Qwen3.8 supports DFlash2 text generation acceleration. See the supported model matrix for configuration and combination limits.
- Dashboard runtime status, logs, dynamic log-level changes and local redacted diagnostic exports.

## Installation, updates and privacy

RC and stable updates use separate channels. Models must be downloaded separately; the installer does not include model weights.
Loopback is the default. Optional LAN mode uses HTTPS, API keys and Keychain credential storage.
Diagnostic exports are generated locally, exclude prompts/credentials and are not automatically uploaded.

## Known limitations

- Image input accepts JPEG/PNG/WebP base64, not remote image URLs. Video or audio generation is not promised.
- Listing embedding, reranker, ASR or TTS metadata does not mean the generation backend can load those models.
- DiffusionGemma has no KV cache, Prompt Lookup or MTP; its separate path supports a smaller sampling-parameter set.
- Model support does not grant commercial-use or redistribution rights; upstream terms apply.
