# cxx-mlx P5.7: Stream/Device + 批量 eval + compile_clear_cache Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retrofit the entire op surface (~70 user-facing ops) so each function gets a `_on(target)` variant accepting `impl Into<StreamOrDevice>`; add batch `eval`/`async_eval`; bind `compile::clear_cache`.

**Architecture:** B-2 双函数模式（`add(a,b)` 默认 + `add_on(a,b,target)` 显式）。`StreamOrDevice` 是公开 enum，`encode()` 序列化到 4 个 FFI 标量参数（`bool has, bool dev_only, u8 dev_type, i32 stream_idx`）。declarative macro `op_with_stream!` 从单一定义自动派生两个 fn。所有现有调用站点零改动（默认变体签名不变）。

**Tech Stack:** Rust 2021 + cxx 1.0 + MLX C++. Spec: [docs/superpowers/specs/2026-05-06-cxx-mlx-p5.7-stream-architecture-design.md](../specs/2026-05-06-cxx-mlx-p5.7-stream-architecture-design.md).

/// Target stream or device for an op. Mirrors MLX C++
/// `mlx::core::StreamOrDevice` (`std::variant<monostate, Stream, Device>`).
///
/// Used by `*_on` op variants. Construct via:
/// - `StreamOrDevice::default()` or `()`.into()` — use MLX's current default
/// - `stream.into()` — explicit stream
/// - `device.into()` — that device's default stream
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum StreamOrDevice {
    /// Use MLX's current default stream for the calling thread.
    #[default]
    Default,
    /// Use the specified stream.
    Stream(Stream),
    /// Use the default stream of the specified device.
    Device(crate::Device),
}

impl From<Stream> for StreamOrDevice {
    fn from(s: Stream) -> Self {
        StreamOrDevice::Stream(s)
    }
}

impl From<crate::Device> for StreamOrDevice {
    fn from(d: crate::Device) -> Self {
        StreamOrDevice::Device(d)
    }
}

impl From<()> for StreamOrDevice {
    fn from(_: ()) -> Self {
        StreamOrDevice::Default
    }
}

impl StreamOrDevice {
    /// Encode for FFI: `(has_target, is_device_only, device_type_repr, stream_index)`.
    /// `Default` → `(false, false, 0, 0)`. `Device` → `(true, true, dt, 0)`.
    /// `Stream` → `(true, false, dt, idx)`.
    pub(crate) fn encode(self) -> (bool, bool, u8, i32) {
        match self {
            StreamOrDevice::Default => (false, false, 0, 0),
            StreamOrDevice::Device(d) => (true, true, d.device_type as u8, 0),
            StreamOrDevice::Stream(s) => (true, false, s.device.device_type as u8, s.index),
        }
    }
}
```

- [ ] **Step 1.4: Add C++ helper to `mlx-sys/shim/include/cxx_mlx_shim/shim_helpers.h`**

```cpp
// === P5.7 StreamOrDevice decoding ===
//
// 4-arg encoding from Rust:
//   has_target=false                  → std::monostate (use MLX default)
//   has_target=true, is_device_only=true   → Device only
//   has_target=true, is_device_only=false  → Stream(idx, Device(device_type, 0))
//
// device_type: 0=cpu, 1=gpu (matches mlx::core::Device::DeviceType).

#include "mlx/device.h"
#include "mlx/stream.h"
#include "mlx/utils.h"

inline mlx::core::Device decode_device(uint8_t device_type) {
  switch (device_type) {
    case 0: return mlx::core::Device(mlx::core::Device::DeviceType::cpu, 0);
    case 1: return mlx::core::Device(mlx::core::Device::DeviceType::gpu, 0);
    default:
      throw std::runtime_error("decode_device: unknown DeviceType");
  }
}

inline mlx::core::StreamOrDevice decode_stream_or_device(
    bool has_target,
    bool is_device_only,
    uint8_t device_type,
    int32_t stream_index) {
  if (!has_target) {
    return std::monostate{};
  }
  auto dev = decode_device(device_type);
  if (is_device_only) {
    return dev;
  }
  return mlx::core::Stream(stream_index, dev);
}
```

// === P5.7 batch eval ===

void eval_many(rust::Slice<const MlxArray* const> arrays) {
  std::vector<mlx::core::array> vec;
  vec.reserve(arrays.size());
  for (const MlxArray* p : arrays) {
    vec.push_back(*p);
  }
  mlx::core::eval(vec);
}

void async_eval_many(rust::Slice<const MlxArray* const> arrays) {
  std::vector<mlx::core::array> vec;
  vec.reserve(arrays.size());
  for (const MlxArray* p : arrays) {
    vec.push_back(*p);
  }
  mlx::core::async_eval(vec);
}

```rust
/// Evaluate multiple arrays in one call. Blocks until all are computed.
/// More efficient than calling `Array::eval()` per array.
pub fn eval(arrays: &[&Array]) -> Result<()> {
    let raw: Vec<*const _> = arrays.iter().map(|a| a.as_inner() as *const _).collect();
    // SAFETY: each pointer borrows a live `&Array` for this call's duration.
    unsafe { mlx_sys::stream::ffi::eval_many(&raw) }.map_err(Error::from)
}

/// Asynchronously evaluate multiple arrays. Returns immediately; arrays
/// will become available as their computation completes (later `eval` /
/// `to_vec` / `item` will block until the async work finishes).
pub fn async_eval(arrays: &[&Array]) -> Result<()> {
    let raw: Vec<*const _> = arrays.iter().map(|a| a.as_inner() as *const _).collect();
    // SAFETY: each pointer borrows a live `&Array` for this call's duration.
    unsafe { mlx_sys::stream::ffi::async_eval_many(&raw) }.map_err(Error::from)
}
```

```rust
//! Internal macros for the ops layer.
//!
//! `op_with_stream!` defines an op as a pair of functions: a default
//! variant (no stream arg) and a `*_on` variant taking
//! `impl Into<StreamOrDevice>`. Both delegate to the same FFI bridge
//! function with 4 trailing stream params.

/// Generates default + `_on` variants of an op.
///
/// Usage:
/// ```ignore
/// op_with_stream! {
///     /// Doc comment for the op.
///     pub fn add(a: &Array, b: &Array) -> Result<Array>
///         => mlx_sys::array::ffi::add(a.as_inner(), b.as_inner());
/// }
/// ```
///
/// Generates:
/// ```ignore
/// pub fn add(a: &Array, b: &Array) -> Result<Array> { ... }
/// pub fn add_on(a: &Array, b: &Array, target: impl Into<StreamOrDevice>) -> Result<Array> { ... }
/// ```
#[macro_export]
macro_rules! op_with_stream {
    (
        $(#[$attr:meta])*
        $vis:vis fn $name:ident ( $($arg:ident : $ty:ty),* $(,)? ) -> $ret:ty
            => $bridge:ident :: ffi :: $bridge_fn:ident ( $($bridge_arg:expr),* $(,)? ) ;
    ) => {
        $crate::__paste_macro::paste! {
            $(#[$attr])*
            $vis fn $name( $($arg: $ty),* ) -> $ret {
                [<$name _on>]( $($arg,)* () )
            }

            #[doc = concat!("Stream-targeted variant of `", stringify!($name), "`. ",
                            "Pass `()` for default, `Stream`, or `Device`.")]
            $vis fn [<$name _on>]( $($arg: $ty,)* target: impl Into<$crate::StreamOrDevice> ) -> $ret {
                let (has, dev_only, dev_t, idx) = target.into().encode();
                // SAFETY: target.encode() produces valid 4-param representation;
                // bridge fn takes them via cxx-generated `unsafe extern "C++"`.
                let inner = unsafe {
                    mlx_sys::$bridge::ffi::$bridge_fn(
                        $($bridge_arg,)*
                        has, dev_only, dev_t, idx,
                    )
                }
                .map_err($crate::Error::from)?;
                Ok($crate::Array::from_inner(inner))
            }
        }
    };
}

// Re-export `paste` for the macro's use without forcing every caller to
// add `paste` to their dependencies. (paste is already in cxx-mlx via the
// bridge; if not, add to mlx/Cargo.toml.)
#[doc(hidden)]
pub use paste as __paste_macro;
```
