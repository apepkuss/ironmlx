**Goal:** Bind ~30 Tier-1 inference ops (comparisons, softmax, sort/topk family, astype, constructors, expand/squeeze, maximum/minimum, clip), each with default + `_on(target)` variant per P5.7 architecture.

**Architecture:** New ops follow the P5.7 patterns: simple ops use `op_with_stream!` macro; complex signatures (Option<&Array>, generic shapes, multi-overload) hand-written. New modules `ops/sort.rs`, `ops/cast.rs`, `ops/constructors.rs` for natural grouping.

**Tech Stack:** Rust 2021 + cxx 1.0 + MLX C++. Spec: [docs/superpowers/specs/2026-05-06-cxx-mlx-p5.5-tier1-ops-design.md](../specs/2026-05-06-cxx-mlx-p5.5-tier1-ops-design.md).

## Conventions Recap

- **TDD per op group**: write test → run (FAIL) → implement → run (PASS) → fmt/lint/build → commit.
- **Project gate before each commit**:
  ```
  cargo fmt
  cargo +nightly fmt --all -- --check
  cargo +nightly clippy --all-features --workspace --exclude ironmlx-app -- -D warnings
  cargo build --release
  ```
  `MLX_DIR=$HOME/.local/mlx` required.
- **Every new op has both default + `_on` variant from day 1** (P5.7 contract).
- **Bridge signature template** (4 trailing stream params): `bool has_target, bool is_device_only, u8 device_type, i32 stream_index`.
- **Shim impl template**:
  ```cpp
  std::unique_ptr<MlxArray> op_name(/*...args...*/, bool has, bool dev_only, uint8_t dev_t, int32_t idx) {
      auto target = cxx_mlx::helpers::decode_stream_or_device(has, dev_only, dev_t, idx);
      return std::make_unique<MlxArray>(mlx::core::op_name(/*...*/, target));
  }
  ```
- **Each task ends green**: full `cargo test --release` passes before commit.

pub fn clip_on(
    a: &Array, a_min: Option<&Array>, a_max: Option<&Array>,
    target: impl Into<crate::StreamOrDevice>,
) -> Result<Array> {
    let lo_ptr = a_min.map_or(std::ptr::null(), |p| p.as_inner() as *const _);
    let hi_ptr = a_max.map_or(std::ptr::null(), |p| p.as_inner() as *const _);
    let (has, dev_only, dt, idx) = target.into().encode();
    // SAFETY: lo_ptr/hi_ptr null or borrow live for this call.
    let inner = unsafe {
        mlx_sys::array::ffi::clip(a.as_inner(), lo_ptr, hi_ptr, has, dev_only, dt, idx)
    }
    .map_err(crate::Error::from)?;
    Ok(Array::from_inner(inner))
}

std::unique_ptr<MlxArray> softmax(
    const MlxArray& a, rust::Slice<const int32_t> axes, bool precise,
    bool has, bool dev_only, uint8_t dt, int32_t idx) {
    auto target = cxx_mlx::helpers::decode_stream_or_device(has, dev_only, dt, idx);
    if (axes.empty()) {
        return std::make_unique<MlxArray>(mlx::core::softmax(a, precise, target));
    }
    std::vector<int> ax(axes.begin(), axes.end());
    return std::make_unique<MlxArray>(mlx::core::softmax(a, ax, precise, target));
}
