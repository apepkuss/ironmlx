# cxx-mlx P6.5: API Style Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the `mlx` crate's public surface to follow Rust API guidelines: `Shape` newtype, `IntoShape` trait, `std::ops::*` operators, random distribution builders, `ShapeMode` enum, `_mm` → `_matmul` rename, `#[non_exhaustive]` on enums, root re-export trim, `TryFrom` replacing `from_slice`.

**Architecture:** Refactor only — `mlx-sys` shim and cxx::bridge are untouched. All changes are inside `mlx/src/` and `mlx/tests/`. Each task is a breaking change paired with a full caller sweep so the tree compiles and tests pass after every task.

**Tech Stack:** Rust 2021. Spec: [docs/superpowers/specs/2026-05-06-cxx-mlx-p6.5-api-style-design.md](../specs/2026-05-06-cxx-mlx-p6.5-api-style-design.md).

- **TDD per task**: write/extend test → run (FAIL) → implement → run (PASS) → fmt/lint/build → commit.
- **Project gate before every commit** (per `.claude/CLAUDE.md`):
  ```

  cargo +nightly clippy --all-features --workspace --exclude ironmlx-app -- -D warnings
  cargo build --release
  ```
  `MLX_DIR=$HOME/.local/mlx` required for tests.
- **No compatibility code** (Boss rule): when an API changes, delete the old form. No deprecated alias, no shim. Sweep all callers.
- **Each task ends green**: full workspace `cargo test --release` must pass before commit. Mid-task breakage is allowed; commit-time breakage is not.
- **Caller sweep approach**: when an API breaks, the same task updates every caller in `mlx/src/**/*.rs` and `mlx/tests/*.rs`. Use `grep -rn "<old API>" mlx/` to find them, edit each, re-run tests until green.

```rust
//! `Shape` newtype + `IntoShape` trait.

use smallvec::SmallVec;

#[derive(Debug, Clone, PartialEq, Eq, Hash, Default)]
pub struct Shape(SmallVec<[i32; 8]>);

impl Shape {
    /// Empty shape — represents a scalar (rank 0).
    pub fn new() -> Self {
        Self(SmallVec::new())
    }

    pub fn rank(&self) -> usize {
        self.0.len()
    }

    /// Total element count: product of dims. Rank-0 → 1.
    pub fn numel(&self) -> usize {
        self.0.iter().map(|&d| d as usize).product()
    }

    pub fn is_scalar(&self) -> bool {
        self.0.is_empty()
    }

    pub fn as_slice(&self) -> &[i32] {
        self.0.as_slice()
    }
}

impl std::ops::Deref for Shape {
    type Target = [i32];
    fn deref(&self) -> &[i32] {
        self.0.as_slice()
    }
}

impl std::fmt::Display for Shape {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.write_str("[")?;
        for (i, d) in self.0.iter().enumerate() {
            if i > 0 {
                f.write_str(", ")?;
            }
            write!(f, "{d}")?;
        }
        f.write_str("]")
    }
}

impl IntoIterator for Shape {
    type Item = i32;
    type IntoIter = smallvec::IntoIter<[i32; 8]>;
    fn into_iter(self) -> Self::IntoIter {
        self.0.into_iter()
    }
}

impl<'a> IntoIterator for &'a Shape {
    type Item = &'a i32;
    type IntoIter = std::slice::Iter<'a, i32>;
    fn into_iter(self) -> Self::IntoIter {
        self.0.iter()
    }
}

impl From<Vec<i32>> for Shape {
    fn from(v: Vec<i32>) -> Self {
        Self(SmallVec::from_vec(v))
    }
}
impl From<&[i32]> for Shape {
    fn from(s: &[i32]) -> Self {
        Self(SmallVec::from_slice(s))
    }
}
impl<const N: usize> From<[i32; N]> for Shape {
    fn from(a: [i32; N]) -> Self {
        Self(SmallVec::from_slice(&a))
    }
}
impl<const N: usize> From<&[i32; N]> for Shape {
    fn from(a: &[i32; N]) -> Self {
        Self(SmallVec::from_slice(a))
    }
}
impl From<()> for Shape {
    fn from(_: ()) -> Self {
        Shape::new()
    }
}
impl From<i32> for Shape {
    fn from(d: i32) -> Self {
        Self(SmallVec::from_slice(&[d]))
    }
}
impl From<(i32,)> for Shape {
    fn from(t: (i32,)) -> Self {
        Self(SmallVec::from_slice(&[t.0]))
    }
}
impl From<(i32, i32)> for Shape {
    fn from(t: (i32, i32)) -> Self {
        Self(SmallVec::from_slice(&[t.0, t.1]))
    }
}
impl From<(i32, i32, i32)> for Shape {
    fn from(t: (i32, i32, i32)) -> Self {
        Self(SmallVec::from_slice(&[t.0, t.1, t.2]))
    }
}
impl From<(i32, i32, i32, i32)> for Shape {
    fn from(t: (i32, i32, i32, i32)) -> Self {
        Self(SmallVec::from_slice(&[t.0, t.1, t.2, t.3]))
    }
}

/// Anything convertible to `Shape`.
pub trait IntoShape {
    fn into_shape(self) -> Shape;
}

impl<T: Into<Shape>> IntoShape for T {
    fn into_shape(self) -> Shape {
        self.into()
    }
}
```

2. **Delete `Array::from_slice` and replace with `TryFrom`**:

   ```rust
   impl<T: Element, S: IntoShape> TryFrom<(&[T], S)> for Array {
       type Error = Error;
       fn try_from((slice, shape): (&[T], S)) -> Result<Array> {
           let shape = shape.into_shape();
           // Reject negative dims
           if let Some(&d) = shape.iter().find(|&&d| d < 0) {
               return Err(Error::Mlx(format!(
                   "Array::try_from: negative dim {d} in shape {shape}"
               )));
           }
           let expected: usize = shape.numel();
           if slice.len() != expected {
               return Err(Error::ShapeMismatch {
                   expected: shape,
                   actual: Shape::from((slice.len() as i32,)),
               });
           }
           T::array_from(slice, shape.as_slice())
       }
   }
   ```

8. **Implement `std::ops::{Add, Sub, Mul, Div}` for `&Array op &Array`**:
   ```rust
   macro_rules! impl_binop {
       ($trait:ident, $method:ident, $op:literal) => {
           impl<'a, 'b> std::ops::$trait<&'b Array> for &'a Array {
               type Output = Array;
               fn $method(self, rhs: &'b Array) -> Array {
                   crate::ops::binary::$method(self, rhs)
                       .unwrap_or_else(|e| panic!("Array {} Array failed: {e}", $op))
               }
           }
           impl<'a> std::ops::$trait<Array> for &'a Array {
               type Output = Array;
               fn $method(self, rhs: Array) -> Array { self.$method(&rhs) }
           }
           impl<'a> std::ops::$trait<&'a Array> for Array {
               type Output = Array;
               fn $method(self, rhs: &'a Array) -> Array { (&self).$method(rhs) }
           }
           impl std::ops::$trait<Array> for Array {
               type Output = Array;
               fn $method(self, rhs: Array) -> Array { (&self).$method(&rhs) }
           }
       };
   }
   impl_binop!(Add, add, "+");
   impl_binop!(Sub, sub, "-");
   impl_binop!(Mul, mul, "*");
   impl_binop!(Div, div, "/");
   ```
   > Note: `crate::ops::binary` exposes `add`/`subtract`/`multiply`/`divide` (not `sub`/`mul`/`div`). The macro `$method` is the std::ops method name (`add`/`sub`/`mul`/`div`); the actual ops function is `add`/`subtract`/`multiply`/`divide`. Keep two macro arms or inline 4 separate impls — see step 2.3.

   Cleaner inline form:
   ```rust
   impl<'a, 'b> std::ops::Add<&'b Array> for &'a Array {
       type Output = Array;
       fn add(self, rhs: &'b Array) -> Array {
           crate::ops::binary::add(self, rhs).unwrap_or_else(|e| panic!("Array + Array failed: {e}"))
       }
   }
   // Sub → ops::binary::subtract; Mul → multiply; Div → divide
   // Plus owned variants for each (3 variants × 4 ops = 12 thin wrappers).
   ```

9. **Implement `Neg`**:

   ```rust
   impl std::ops::Neg for &Array {
       type Output = Array;
       fn neg(self) -> Array {
           crate::ops::binary::negative(self).unwrap_or_else(|e| panic!("-Array failed: {e}"))
       }
   }
   impl std::ops::Neg for Array {
       type Output = Array;
       fn neg(self) -> Array { -&self }
   }
   ```

10. **Keep all `Array::add` / `Array::mul` / etc. methods** that already exist returning `Result<Array>`. The trait impls call into `ops::binary` directly so the method API and operator API are independent paths.

- [ ] **Step 2.5: Sweep all callers**

Run:
```bash
grep -rn "Array::from_slice\|\.from_slice(" mlx/src/ mlx/tests/
grep -rn "\.shape()\.as_slice\|let .*shape.*= .*\.shape()" mlx/src/ mlx/tests/
```

For each match:
- `Array::from_slice(&[v], &[s])` → `Array::try_from((&[v][..], [s])).unwrap()` (in tests; in src use `?`)
- Tests using `array.shape()` returning `SmallVec`: now returns `Shape`. If they call `.as_slice()`, that still works (Shape derefs to slice). If they index by `[i]`, that works (Shape derefs).
- Anywhere that compared shapes to `Vec<i32>`, change RHS to `Shape::from(...)`.

Common rewrite recipes:
| Before | After |
|---|---|
| `Array::from_slice(&xs, &[a, b])` | `Array::try_from((&xs[..], (a, b)))` |
| `Array::from_slice(&xs, &shape_vec)` | `Array::try_from((&xs[..], shape_vec))` |
| `array.shape()` returning `SmallVec<[i32;8]>` for read | unchanged — `Shape` derefs to `[i32]` |
| `assert_eq!(a.shape(), smallvec![2, 3])` | `assert_eq!(a.shape(), Shape::from((2, 3)))` |
| `Array::zeros(&[2, 3], Dtype::Float32)` | `Array::zeros((2, 3), Dtype::Float32)` |

```rust
pub fn split(key: &Array) -> Result<(Array, Array)> {
    let mut pair = mlx_sys::random::ffi::split(key.as_inner()).map_err(Error::from)?;
    let first = mlx_sys::random::ffi::key_pair_take_first(pair.pin_mut()).map_err(Error::from)?;
    let second = mlx_sys::random::ffi::key_pair_take_second(pair.pin_mut()).map_err(Error::from)?;
    Ok((Array::from_inner(first), Array::from_inner(second)))
}
```

```rust
use crate::{Array, Dtype, Error, IntoShape, Result, Shape};

pub struct Uniform<'k> {
    low: f64,
    high: f64,
    shape: Shape,
    dtype: Dtype,
    key: Option<&'k Array>,
}

impl<'k> Uniform<'k> {
    pub fn new() -> Self {
        Self {
            low: 0.0,
            high: 1.0,
            shape: Shape::new(),
            dtype: Dtype::Float32,
            key: None,
        }
    }

    pub fn low(mut self, v: f64) -> Self {
        self.low = v;
        self
    }
    pub fn high(mut self, v: f64) -> Self {
        self.high = v;
        self
    }
    pub fn shape<S: IntoShape>(mut self, s: S) -> Self {
        self.shape = s.into_shape();
        self
    }
    pub fn dtype(mut self, d: Dtype) -> Self {
        self.dtype = d;
        self
    }
    pub fn key(mut self, k: &'k Array) -> Self {
        self.key = Some(k);
        self
    }

    pub fn sample(self) -> Result<Array> {
        // Build low/high as scalar Arrays
        let low_arr: Array = (&[self.low as f32][..], (1,)).try_into()?;
        let high_arr: Array = (&[self.high as f32][..], (1,)).try_into()?;
        let k = self.key.map_or(std::ptr::null(), |a| a.as_inner() as *const _);
        // SAFETY: k is null or borrow valid for this call.
        let inner = unsafe {
            mlx_sys::random::ffi::uniform(
                low_arr.as_inner(),
                high_arr.as_inner(),
                self.shape.as_slice(),
                self.dtype.as_u8(),
                k,
            )
        }
        .map_err(Error::from)?;
        Ok(Array::from_inner(inner))
    }
}

impl<'k> Default for Uniform<'k> {
    fn default() -> Self {
        Self::new()
    }
}

/// Free-function entry point: `random::uniform().shape((3, 4)).sample()?`.
pub fn uniform<'k>() -> Uniform<'k> {
    Uniform::new()
}
```
