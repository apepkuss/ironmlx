# MTP Phase 5.1 Server API Validation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Validate that Phase 5 server/API MTP diagnostics work on real local MTP models.

**Architecture:** This phase does not change runtime behavior. It starts `ironmlx serve` with MTP enabled for each supported Qwen MTP model, sends real OpenAI/Anthropic HTTP requests, and records `/healthz.mtp` snapshots plus small OpenAI and Anthropic streaming smoke checks.

**Tech Stack:** Rust release binaries, `curl`, `jq`, `iron-bench`, local MLX runtime via `MLX_DIR=$HOME/.local/mlx`.

---

**Files:**
- Create: `docs/benchmarks/mtp-phase5.1-server-api-validation/<timestamp>/summary.md`
- Create: `docs/benchmarks/mtp-phase5.1-server-api-validation/<timestamp>/summary.csv`

- Create: `docs/benchmarks/mtp-phase5.1-server-api-validation/<timestamp>/bench/*.csv`
- Create: `docs/benchmarks/mtp-phase5.1-server-api-validation/latest.txt`

- [x] **Step 1: Build release binaries**

Run:

```bash
MLX_DIR=$HOME/.local/mlx cargo build --release -p ironmlx --bin ironmlx
cargo build --release -p iron-bench
```

Expected: both release binaries exist under `target/release/`.

- [x] **Step 2: Start each MTP server**

Run `ironmlx serve` once per model with:

```bash
MLX_DIR=$HOME/.local/mlx target/release/ironmlx serve \
  --model <base-snapshot> \
  --host 127.0.0.1 \
  --port <port> \
  --b-max 1 \
  --mtp-model-dir <mtp-snapshot>
```

Expected: `/healthz` becomes reachable.

- [x] **Step 3: Assert initial `/healthz.mtp` state**

Expected:

```text
enabled=true
draft_tokens=<model-aware default>
prefill_count=0
step_count=0
```

- [x] **Step 4: Assert greedy OpenAI request uses MTP**

Send non-streaming `/v1/chat/completions` with `temperature=0`.

Expected: HTTP 200 and `/healthz.mtp.prefill_count` plus `/healthz.mtp.step_count` increase.

- [x] **Step 5: Assert non-greedy OpenAI request falls back without MTP counters**

Send non-streaming `/v1/chat/completions` with `temperature=0.7`.

Expected: HTTP 200 and MTP counters remain unchanged from Step 4.

- [x] **Step 6: Assert greedy Anthropic request uses MTP**

Send non-streaming `/v1/messages` with `temperature=0`.

Expected: HTTP 200 and MTP counters increase again.

- [x] **Step 7: Run OpenAI streaming smoke benchmark**

Run:

```bash
target/release/iron-bench \
  --target <model>_mtp=http://127.0.0.1:<port> \
  --model-dir <base-snapshot> \
  --model <model-label> \
  --prompt-len 128 \
  --max-tokens 32 \
  --runs 1 \
  --warmup 1 \
  --timeout 600 \
  --format csv
```

Expected: one measured OpenAI streaming row with TTFT, TG, and E2E values.

- [x] **Step 8: Assert greedy Anthropic streaming request uses MTP**

Send streaming `/v1/messages` with `temperature=0`.

Expected:

```text
HTTP 200
event: message_start
event: content_block_start
event: content_block_delta
event: content_block_stop
event: message_delta
event: message_stop
no event: error
/healthz.mtp.prefill_count increases
/healthz.mtp.step_count increases
```

- [x] **Step 9: Save summary artifacts**

Expected: summary artifacts are written under `docs/benchmarks/mtp-phase5.1-server-api-validation/2026-06-08-134532/`.
