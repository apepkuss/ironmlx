# cxx-mlx P5.5: 第 1 优先算子补漏 设计文档

**日期：** 2026-05-06
**作者：** Claude（与 Boss 协作）
**目标阶段：** P5.5 — 推理基础设施第 1 优先算子补漏

---

## 1. 目标与范围

P0–P5 + P5.7 完成后，cxx-mlx 已绑定 ~80 个算子并支持 Stream/Device 调度，但仍缺**比较运算**（mask 构造）、**softmax/采样**、**dtype 转换**、**构造函数家族**等推理路径上的核心算子。

P5.5 一次性补齐 **~30 个第 1 优先算子**。所有新增算子从 day 1 起就提供 `_on` 变体（继承 P5.7 的 `op_with_stream!` macro 或手写模板）。

### 1.1 范围列表

| 类别 | 算子 | 数量 |
|---|---|---|
| **比较运算** | `equal` / `not_equal` / `less` / `less_equal` / `greater` / `greater_equal` | 6 |
| **softmax / 采样** | `softmax` / `topk` / `partition` / `argpartition` / `sort` / `argsort` | 6 |
| **dtype 转换** | `astype` | 1 |
| **构造函数** | `arange` / `linspace` / `ones` / `ones_like` / `zeros_like` / `full` / `full_like` / `eye` / `identity` / `tri` / `tril` / `triu` | 12 |
| **shape**| `expand_dims` / `squeeze` | 2 |
| **element-wise binary** | `maximum` / `minimum` | 2 |
| **数值范围** | `clip` | 1 |

总计 **30 个新算子** + 各自的 `_on` 变体。

### 1.2 不在范围内

- 第 2 优先算子（cumsum / 累积归约 / 数值卫生 / 一元补完 / pad / repeat / argmin / logsumexp 等）→ P5.6
- conv / linalg / fft → P7+
- 训练相关 / scatter family / view / as_strided

## 2. 架构

P5.7 的 3 层 FFI + macro / 手写 `_on` 模式不变。新增算子直接复用：

- 简单单/双 array op + 标量参数 → `op_with_stream!` 宏
- 复杂签名（generic shape、optional 参数、Vec<Array> 返回、tuple 返回）→ 手写 `_on`

各算子放置在合适的 `mlx/src/ops/<module>.rs`：

| 算子 | 模块 |
|---|---|
| equal / not_equal / less / less_equal / greater / greater_equal | `ops/binary.rs` |
| maximum / minimum | `ops/binary.rs` |
| softmax | `ops/unary.rs`（虽然有 axis 参数，但语义上是按 axis 归一化） |
| topk / partition / argpartition / sort / argsort | `ops/sort.rs`（新建） |
| astype | `ops/cast.rs`（新建） |
| arange / linspace / ones / ones_like / zeros_like / full / full_like / eye / identity / tri / tril / triu | `ops/constructors.rs`（新建） |
| expand_dims / squeeze | `ops/shape.rs` |
| clip | `ops/binary.rs`（虽然 3-input 但是 element-wise） |

## 3. 详细设计

### 3.1 比较运算（6 个）

每个都是 `(a: &Array, b: &Array) -> Result<Array>`，返回 bool array。FFI 直对应 MLX。

```cpp
MLX_API array equal(const array& a, const array& b, StreamOrDevice s = {});
// not_equal / less / less_equal / greater / greater_equal 同形
```

Rust safe API（`mlx/src/ops/binary.rs` 内追加）：

```rust
op_with_stream! {
    /// Element-wise `a == b`. Returns bool array.
    pub fn equal(a: &Array, b: &Array) -> Result<Array>
        => array::ffi::equal(a.as_inner(), b.as_inner());
}
// not_equal / less / less_equal / greater / greater_equal 同样
```

### 3.2 softmax + 采样路径（6 个）

#### 3.2.1 `softmax`

```cpp
MLX_API array softmax(const array& a, const std::vector<int>& axes, bool precise = false, StreamOrDevice s = {});
MLX_API array softmax(const array& a, int axis, bool precise = false, StreamOrDevice s = {});
MLX_API array softmax(const array& a, bool precise = false, StreamOrDevice s = {});  // last axis
```

Rust 设计统一在一个函数 + `IntoAxes`（参考 reduction 风格）：

```rust
pub fn softmax<A: IntoAxes>(a: &Array, axes: A, precise: bool) -> Result<Array>;
// axes = All → softmax over last axis (default behavior)
// axes = Axis(i) → over axis i
// axes = Axes(&[i, j]) → over multiple axes
```

放置在 `ops/unary.rs` 末尾（虽然有 axes 参数，但形态接近 reduction-shaped unary）。

#### 3.2.2 sort / argsort / partition / argpartition / topk

```cpp
MLX_API array sort(const array& a, int axis, StreamOrDevice s = {});
MLX_API array sort(const array& a, StreamOrDevice s = {});  // axis = -1
MLX_API array argsort(const array& a, int axis, StreamOrDevice s = {});
MLX_API array argsort(const array& a, StreamOrDevice s = {});

MLX_API array partition(const array& a, int kth, int axis, StreamOrDevice s = {});
MLX_API array argpartition(const array& a, int kth, int axis, StreamOrDevice s = {});

MLX_API array topk(const array& a, int k, int axis, StreamOrDevice s = {});
MLX_API array topk(const array& a, int k, StreamOrDevice s = {});  // axis = -1
```

Rust：新建 `mlx/src/ops/sort.rs`：

```rust
pub fn sort(a: &Array, axis: i32) -> Result<Array>;
pub fn argsort(a: &Array, axis: i32) -> Result<Array>;
pub fn partition(a: &Array, kth: i32, axis: i32) -> Result<Array>;
pub fn argpartition(a: &Array, kth: i32, axis: i32) -> Result<Array>;
pub fn topk(a: &Array, k: i32, axis: i32) -> Result<Array>;
// 各自带 _on 变体
```

不模拟 MLX 的"无 axis 默认 -1"重载，调用方传 `-1` 即可。

> **注意**：`topk` MLX 只返回 values（`array`，不是 (values, indices) 的 pair）。如果需要 indices，调用 `argpartition` 然后 `take_along_axis`。这与 PyTorch `torch.topk` 不同。

### 3.3 dtype 转换（`astype`）

```cpp
MLX_API array astype(array a, Dtype dtype, StreamOrDevice s = {});
```

Rust：新建 `mlx/src/ops/cast.rs`：

```rust
pub fn astype(a: &Array, dtype: Dtype) -> Result<Array>;
// _on 变体
```

也可作为 `Array::astype(&self, dtype) -> Result<Array>` 方法，与 free fn 对称。

### 3.4 构造函数（12 个）

```cpp
MLX_API array arange(double start, double stop, double step, StreamOrDevice s = {});
MLX_API array arange(int start, int stop, int step, StreamOrDevice s = {});
// + 多个无 step / 无 start 的重载

MLX_API array linspace(double start, double stop, int num, Dtype dtype, StreamOrDevice s = {});

MLX_API array ones(const Shape& shape, Dtype dtype, StreamOrDevice s = {});
MLX_API array ones_like(const array& a, StreamOrDevice s = {});
MLX_API array zeros_like(const array& a, StreamOrDevice s = {});
MLX_API array full(Shape shape, array vals, Dtype dtype, StreamOrDevice s = {});
MLX_API array full_like(const array& a, array vals, StreamOrDevice s = {});

MLX_API array eye(int n, int m, int k, Dtype dtype, StreamOrDevice s = {});
MLX_API array identity(int n, Dtype dtype, StreamOrDevice s = {});
MLX_API array tri(int n, int m, int k, Dtype dtype, StreamOrDevice s = {});
MLX_API array tril(array x, int k, StreamOrDevice s = {});
MLX_API array triu(array x, int k, StreamOrDevice s = {});
```

Rust：新建 `mlx/src/ops/constructors.rs`：

```rust
// arange — 用 f64 统一接收，Rust 不模拟 int/double 重载
pub fn arange(start: f64, stop: f64, step: f64, dtype: Dtype) -> Result<Array>;
// 调用方传 step=1.0 模拟 "无 step" 重载

pub fn linspace(start: f64, stop: f64, num: i32, dtype: Dtype) -> Result<Array>;

pub fn ones<S: IntoShape>(shape: S, dtype: Dtype) -> Result<Array>;
pub fn ones_like(a: &Array) -> Result<Array>;
pub fn zeros_like(a: &Array) -> Result<Array>;
pub fn full<S: IntoShape>(shape: S, vals: &Array, dtype: Dtype) -> Result<Array>;
pub fn full_like(a: &Array, vals: &Array) -> Result<Array>;

pub fn eye(n: i32, m: i32, k: i32, dtype: Dtype) -> Result<Array>;
pub fn identity(n: i32, dtype: Dtype) -> Result<Array>;

pub fn tri(n: i32, m: i32, k: i32, dtype: Dtype) -> Result<Array>;
pub fn tril(x: &Array, k: i32) -> Result<Array>;
pub fn triu(x: &Array, k: i32) -> Result<Array>;
// 全部带 _on 变体
```

> **注意**：`Array::zeros` 已经存在（`mlx/src/array.rs`）。新增 `zeros_like` 等 helper 在 `ops::constructors`。`Array::zeros` 保持不变。

### 3.5 shape（2 个）

```cpp
MLX_API array squeeze(const array& a, int axis, StreamOrDevice s = {});
MLX_API array squeeze(const array& a, StreamOrDevice s = {});  // 全 squeeze
MLX_API array squeeze(const array& a, const std::vector<int>& axes, StreamOrDevice s = {});

MLX_API array expand_dims(const array& a, int axis, StreamOrDevice s = {});
MLX_API array expand_dims(const array& a, const std::vector<int>& axes, StreamOrDevice s = {});
```

追加到 `mlx/src/ops/shape.rs`：

```rust
pub fn squeeze<A: IntoAxes>(a: &Array, axes: A) -> Result<Array>;
pub fn expand_dims<A: IntoAxes>(a: &Array, axes: A) -> Result<Array>;
// _on 变体
```

`IntoAxes::All` 表示 squeeze 全部 size-1 维。`IntoAxes::Axis(i)` 单 axis；`IntoAxes::Axes(&[..])` 多 axes。

### 3.6 element-wise binary（2 个）

```cpp
MLX_API array maximum(const array& a, const array& b, StreamOrDevice s = {});
MLX_API array minimum(const array& a, const array& b, StreamOrDevice s = {});
```

追加到 `mlx/src/ops/binary.rs`：

```rust
op_with_stream! {
    /// Element-wise max(a, b).
    pub fn maximum(a: &Array, b: &Array) -> Result<Array>
        => array::ffi::maximum(a.as_inner(), b.as_inner());
}
// minimum 同样
```

### 3.7 clip（1 个）

```cpp
MLX_API array clip(const array& a, std::optional<array> a_min, std::optional<array> a_max, StreamOrDevice s = {});
```

`Option<&Array>` × 2，手写 `_on`：

```rust
pub fn clip(a: &Array, a_min: Option<&Array>, a_max: Option<&Array>) -> Result<Array>;
pub fn clip_on(
    a: &Array, a_min: Option<&Array>, a_max: Option<&Array>,
    target: impl Into<StreamOrDevice>
) -> Result<Array>;
```

放置在 `mlx/src/ops/binary.rs`（虽然 3-input，但语义是 element-wise 范围约束）。

### 3.8 Array 方法对称

每个 free function 都加对应的 `Array::*` 方法（`_on` 同步加上）：

```rust
impl Array {
    // 比较
    pub fn equal(&self, rhs: &Array) -> Result<Array>;
    pub fn equal_on(&self, rhs: &Array, target: impl Into<StreamOrDevice>) -> Result<Array>;
    // not_equal / less / less_equal / greater / greater_equal 同形
    
    // softmax
    pub fn softmax<A: IntoAxes>(&self, axes: A, precise: bool) -> Result<Array>;
    pub fn softmax_on<A: IntoAxes>(&self, axes: A, precise: bool, target: impl Into<StreamOrDevice>) -> Result<Array>;
    
    // 采样
    pub fn sort(&self, axis: i32) -> Result<Array>;
    // argsort / partition / argpartition / topk 同形
    
    // dtype
    pub fn astype(&self, dtype: Dtype) -> Result<Array>;
    
    // shape
    pub fn squeeze<A: IntoAxes>(&self, axes: A) -> Result<Array>;
    pub fn expand_dims<A: IntoAxes>(&self, axes: A) -> Result<Array>;
    
    // 二元
    pub fn maximum(&self, rhs: &Array) -> Result<Array>;
    pub fn minimum(&self, rhs: &Array) -> Result<Array>;
    
    // clip
    pub fn clip(&self, a_min: Option<&Array>, a_max: Option<&Array>) -> Result<Array>;
}
```

构造函数（`arange` / `ones` / `eye` / 等）不需要 method 形式（无 `&self` 来源）。但 `tril` / `triu` / `ones_like` / `zeros_like` / `full_like` / `astype` 都接受 `&Array` 输入，应有 method 变体。

## 5. 任务分解

5 个任务：

| # | 任务 | 算子数 | 模块 |
|---|---|---|---|
| 1 | 比较运算 + maximum/minimum/clip | 9 | `ops/binary.rs` |
| 2 | softmax + sort/argsort/topk/partition/argpartition | 6 | `ops/unary.rs` + `ops/sort.rs`（新） |
| 3 | astype | 1 | `ops/cast.rs`（新） |
| 4 | 构造函数（arange/linspace/ones/...../tril/triu） | 12 | `ops/constructors.rs`（新） |
| 5 | expand_dims / squeeze | 2 | `ops/shape.rs` |

每任务结尾：
- TDD（写测试 → FAIL → 实现 → PASS）
- 项目门禁全绿
- 单一独立 commit

任务间无依赖，可按上述顺序执行。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| MLX 重载多（arange / softmax / sort 等）| Rust 设计统一一个签名收到所有重载——用 `IntoAxes` / 必填参数 / f64 统一 |
| `clip` 双 Option 参数 | 手写 `_on`，参考 P5.7 fast/quantization 的 `Option<&Array>` 风格 |
| 新 `Array` 方法与既有 trait method 冲突 | 检查命名（如 `astype` 与 `Array::dtype()` 不冲突） |
| 构造函数文件膨胀 | 新建 `ops/constructors.rs`，不堆到现有文件 |
| 测试覆盖不足 | 每类算子至少 1 个行为测试 + 1 个 `_on` smoke |
