## 1. 目标与范围

P5.5 落地了 30 个第 1 优先算子。P5.6 补完**剩余的推理常用算子**，包括一元补完、新 reduction、累积归约、数值卫生、shape 操作。

### 1.1 范围（25 个算子）

| 类别 | 算子 | 数量 |
|---|---|---|
| **一元补完** | `abs`、`sign`、`floor`、`ceil`、`round` | 5 |
| **三角函数** | `sin`、`cos`、`tan`、`expm1` | 4 |
| **逻辑非** | `logical_not` | 1 |
| **二元补完** | `power`、`logaddexp`、`remainder` | 3 |
| **reduction 补完** | `argmin`、`all`、`any`、`prod`、`logsumexp` | 5 |
| **累积归约** | `cumsum`、`cumprod` | 2 |
| **数值卫生** | `isnan`、`isinf`、`isfinite`、`nan_to_num` | 4 |
| **shape 补完** | `flatten`、`repeat` | 2 |

**总计 26 个算子**（25-26 都对，依 isnan/isclose 包含与否）。

### 1.2 不在范围内

- conv / linalg / fft → P7+
- `isclose` / `allclose`（模糊比较）—— 类似数值卫生但形态特殊（带 tol/rtol 参数），单列不补可由 `isfinite + abs(a-b) < tol` 组合
- `cummax` / `cummin` / `logcumsumexp` —— 极冷门，推迟
- `tile`（与 `repeat` 重叠）—— `repeat` 已覆盖；推迟
- 反三角 `arcsin/arccos/arctan` 等 —— 极冷门，推迟
- 训练相关 / scatter family

## 2. 架构

P5.7 的 3 层 FFI + macro / 手写 `_on` 模式不变。新算子放置：

| 算子 | 模块 |
|---|---|
| abs / sign / floor / ceil / round / sin / cos / tan / expm1 / logical_not / isnan / isinf / isfinite / nan_to_num | `ops/unary.rs` |
| power / logaddexp / remainder | `ops/binary.rs` |
| argmin / all / any / prod / logsumexp | `ops/reduction.rs` |
| cumsum / cumprod | `ops/cumulative.rs`（新建） |
| flatten / repeat | `ops/shape.rs` |

`isnan` / `isinf` / `isfinite` 返回 bool；`nan_to_num` 替换非有限值。

## 3. 详细设计

### 3.1 一元补完（14 个）

MLX 签名都是 `array f(const array& a, StreamOrDevice s = {})`，例外：
- `round(a, decimals: int, s)` —— 多一个 decimals 参数
- `nan_to_num(a, nan: f32, posinf: Option<f32>, neginf: Option<f32>, s)` —— 多个标量 + 可选

```rust
op_with_stream! {
    pub fn abs(a: &Array) -> Result<Array> => array::ffi::abs(a.as_inner());
}
// sign / floor / ceil / sin / cos / tan / expm1 / logical_not / isnan / isinf / isfinite 同形
```

`round` 手写（多参数）：
```rust
pub fn round(a: &Array, decimals: i32) -> Result<Array>;
pub fn round_on(a: &Array, decimals: i32, target: impl Into<StreamOrDevice>) -> Result<Array>;
```

`nan_to_num` 手写（Option scalar）：
```rust
pub fn nan_to_num(
    a: &Array,
    nan: f32,
    posinf: Option<f32>,
    neginf: Option<f32>,
) -> Result<Array>;
// + _on 变体
```

### 3.2 二元补完（3 个）

```rust
op_with_stream! {
    pub fn power(a: &Array, b: &Array) -> Result<Array> => array::ffi::power(a.as_inner(), b.as_inner());
}
// logaddexp / remainder 同形
```

放置在 `mlx/src/ops/binary.rs`。

### 3.3 reduction 补完（5 个）

`argmin` / `all` / `any` / `prod` / `logsumexp` 都接 `IntoAxes` + `keepdim: bool`，与 P1b2a 已有的 `sum`/`mean`/`max`/`min`/`argmax` 同形态，**手写**（reduction 的 dispatch 模式不适配宏，参考 P5.7 reduction.rs）：

```rust
pub fn argmin<A: IntoAxes>(a: &Array, axes: A, keepdim: bool) -> Result<Array>;
pub fn argmin_on<A: IntoAxes>(a: &Array, axes: A, keepdim: bool, target: impl Into<StreamOrDevice>) -> Result<Array>;
// all / any / prod / logsumexp 同形
```

### 3.4 累积归约（2 个）

MLX 签名（`mlx/include/mlx/ops.h`）：

```cpp
MLX_API array cumsum(const array& a, int axis, bool reverse = false, bool inclusive = true, StreamOrDevice s = {});
MLX_API array cumprod(const array& a, int axis, bool reverse = false, bool inclusive = true, StreamOrDevice s = {});
```

新建 `mlx/src/ops/cumulative.rs`：

```rust
pub fn cumsum(a: &Array, axis: i32, reverse: bool, inclusive: bool) -> Result<Array>;
pub fn cumprod(a: &Array, axis: i32, reverse: bool, inclusive: bool) -> Result<Array>;
// 各自带 _on 变体
```

可走宏（5 个普通参数）。

### 3.5 数值卫生（4 个）

`isnan` / `isinf` / `isfinite` 是简单一元 → 走宏。
`nan_to_num` 见 § 3.1。

### 3.6 shape 补完（2 个）

```cpp
MLX_API array flatten(const array& a, int start_axis, int end_axis, StreamOrDevice s = {});
MLX_API array flatten(const array& a, StreamOrDevice s = {});  // start=0, end=-1

MLX_API array repeat(const array& arr, int repeats, int axis, StreamOrDevice s = {});
MLX_API array repeat(const array& arr, int repeats, StreamOrDevice s = {});  // axis=-1
```

追加到 `mlx/src/ops/shape.rs`：

```rust
pub fn flatten(a: &Array, start_axis: i32, end_axis: i32) -> Result<Array>;
pub fn repeat(a: &Array, repeats: i32, axis: i32) -> Result<Array>;
// _on 变体
```

不模拟"无 axis 默认"重载，调用方传 `start_axis=0, end_axis=-1` 或 `axis=-1`。

### 3.7 Array 方法对称

每个 free fn 都加对应的 `Array::*` 方法 + `_on` 变体：

```rust
impl Array {
    pub fn abs(&self) -> Result<Array>;
    pub fn abs_on(&self, target: impl Into<StreamOrDevice>) -> Result<Array>;
    // sign / floor / ceil / round / sin / cos / tan / expm1 / logical_not /
    // isnan / isinf / isfinite / nan_to_num — 同形
    
    pub fn power(&self, rhs: &Array) -> Result<Array>;
    // logaddexp / remainder — 同形
    
    pub fn argmin<A: IntoAxes>(&self, axes: A, keepdim: bool) -> Result<Array>;
    // all / any / prod / logsumexp — 同形
    
    pub fn cumsum(&self, axis: i32, reverse: bool, inclusive: bool) -> Result<Array>;
    pub fn cumprod(&self, axis: i32, reverse: bool, inclusive: bool) -> Result<Array>;
    
    pub fn flatten(&self, start_axis: i32, end_axis: i32) -> Result<Array>;
    pub fn repeat(&self, repeats: i32, axis: i32) -> Result<Array>;
}
```

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| `nan_to_num` 的 `Option<f32>` × 2 跨 FFI | 用 `(bool, f32, bool, f32)` 4 标量编码（参考 P4 random `Option<f32>` loc/scale 模式） |
| `power` 与 `Array::pow` 命名冲突 | 检查现有 method 命名；`power(a, b)` free fn 与 `Array::power` method 不冲突（无既有 `pow` 方法） |
| `isnan`/`isinf` 返回 bool | 测试用 `.to_vec::<bool>()`，与 P5.5 比较 ops 一致 |
| `cumsum` reverse/inclusive 语义 | 文档明示 MLX 默认 `reverse=false, inclusive=true`；调用方按需传 |
