# 模型权利边界

IronMLX 提供模型搜索、下载、快照完整性校验和本地加载能力，但不拥有、转让或
重新授权任何模型权利。IronMLX 的软件许可证不适用于模型权重、配置、词表或
模型卡中的其他内容。

## 用户责任

用户选择模型仓库和用途，并负责在使用前查阅上游模型页面（例如 Hugging Face
或 ModelScope）中的模型卡、许可证、gated access 条款、Acceptable Use Policy、
商用限制和再分发限制。用户也负责提供自己有权使用的凭据，并确保实际用途符合
上游条款及适用法律。本文档不是法律意见。

IronMLX 不绕过上游访问控制，不代用户接受许可证或 gated access 条款，也不保证
任一模型可用于特定商业或再分发场景。模型能被技术上加载，只表示当前运行时具备
相应的格式或架构支持，不表示该模型已获授权。

## 下载与发布边界

- App 可以从用户指定的 Hugging Face 或 ModelScope 仓库搜索并下载模型；下载使用
  用户提供的上游凭据，不由 IronMLX 代为授权。
- 下载会将上游引用解析为不可变 revision，并校验文件大小和 SHA-256。这些是
  防止传输或缓存损坏的技术完整性检查，不是许可证或用途合规检查。
- IronMLX 不随 App、DMG、ZIP 或源代码发布包捆绑模型权重，不建立模型镜像，
  也不重新打包或重新发布第三方模型权重。
- 发布包中的模型支持矩阵只描述已验证的运行时能力；用户仍必须回到上游模型
  页面确认模型权利和使用条件。

## 发布验收

每个准备分发的 App、DMG 或 ZIP 都必须通过发布脚本的模型分发边界检查，确认产物
不含常见模型权重文件。该检查不能替代用户对上游许可证的审查，也不改变用户对
所下载模型的全部责任。
