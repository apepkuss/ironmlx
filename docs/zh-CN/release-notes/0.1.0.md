# IronMLX 0.1.0 发布说明

状态：首版发布候选准备中，尚未公开发布。RC 用于测试与反馈，正式版本以发布页面为准。
IronMLX 是面向 Apple Silicon 的本地模型推理 App，提供 Dashboard 和兼容主流客户端的 HTTP API。

## 系统要求

- Apple Silicon（arm64），macOS 26.4 及以上；不支持 Intel Mac。
- 模型所需内存取决于权重大小、量化、上下文长度和并发量；架构受支持不代表任意设备都能加载。
- 自包含 App 内置 Rust/MLX 推理后端，无需另行安装 Python 推理环境。

## 支持的模型架构

| 模型族 | 配置中的 model_type | 输入能力 |
| --- | --- | --- |
| Qwen 3.5 Dense；采用相同架构的 Qwen 3.6 / 3.8 Dense | `qwen3_5` | 文本；具备兼容视觉配置与权重时支持图片 |
| Qwen 3.5 / 3.6 MoE | `qwen3_5_moe` | 文本；具备兼容视觉配置与权重时支持图片 |
| Gemma 4 / Gemma 4 Unified | `gemma4`、`gemma4_unified` | 文本；具备兼容视觉配置与权重时支持图片 |
| GLM-4 MoE Lite | `glm4_moe_lite` | 文本 |
| Llama GQA Dense，包括兼容的 MiniCPM5-1B | `llama` | 文本 |
| MiniCPM-V 4.6 | `minicpmv4_6` | 文本、图片；图片路径需要兼容视觉权重 |
| DiffusionGemma | `diffusion_gemma` | 文本、图片，使用独立 block-diffusion 生成路径 |

这是加载器支持范围，不是所有同名模型或 checkpoint 的通过清单。配置、tokenizer、
chat template、权重布局与量化元数据仍须匹配。[支持模型矩阵](../supported-models.md)
列出已验证 checkpoint、推理模式、工具调用和缓存限制。
支持 Affine 2/4/5/6/8-bit、OptiQ mixed-bit、MXFP4/MXFP8 等权重格式，适用参数以该矩阵为准。

## API 与 Agent 集成

- OpenAI Chat Completions、无状态 Responses，以及 Anthropic Messages 兼容接口，支持 HTTP/SSE 流式输出。
- 原生 reasoning、结构化函数调用及历史回灌，具体能力取决于模型和模板；工具由客户端执行。
- Structured Outputs 与 JSON Schema 约束，支持范围见 [API 兼容矩阵](../../api-compatibility-matrix.md)。
- Hermes Agent、oh-my-pi 的 Provider 配置向导，包含官方配置文档链接及滚动后的紧凑吸顶栏。

## 模型管理与推理优化

- Dashboard 统一模型下载队列，支持 Hugging Face / ModelScope 来源、断点续传、取消、预检、不可变快照和完整性校验。
- 模型加载、卸载、默认模型、固定模型、TTL 管理及配置持久化。
- 连续批处理、分页 KV 与前缀缓存、Prompt Lookup 和内存保护；具体组合受模型及运行模式限制。
- Qwen/Gemma 匹配模型的 MTP 或辅助 drafter；Qwen3.8 DFlash2 使用独立文本执行路径。
  DFlash2 不与 MTP、Prompt Lookup、KV 量化、分页/SSD 前缀缓存或 active KV offload 混用。
- Dashboard 展示运行状态与日志，支持运行时调整日志级别和本地脱敏诊断导出。

## 安装、更新与隐私

公开 RC 产物通过 Developer ID 签名、Apple 公证和票据附加流程生成；使用独立 RC 更新通道，
与稳定版通道分开。App 随附第三方许可证、Notices 与 SBOM，模型权重不随安装包分发。
默认仅监听本机；可选 LAN 模式使用 HTTPS、API Key 和 Keychain 凭据存储。
诊断导出在本机生成，不自动上传，也不包含提示词或凭据。

## 已知限制

- 图片输入接受 JPEG/PNG/WebP base64，不接受远程图片 URL；不承诺视频或音频生成。
- 模型列表识别 embedding、reranker、ASR 或 TTS 元数据，不代表这些模型可由生成后端加载。
- DiffusionGemma 不支持 KV cache、Prompt Lookup 或 MTP；采样参数限于其独立路径支持的集合。
- 全新系统安装尚未覆盖；首版没有正式旧版本，公开版本间升级将在后续版本验证。
- 模型支持不代表商业使用或再分发授权，请遵守上游模型条款。

验收证据和未覆盖范围见 [RC 验收记录](../release-acceptance/0.1.0-rc.1.md)。
