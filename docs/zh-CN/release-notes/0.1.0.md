# IronMLX 0.1.0 发布说明

状态：首版发布候选准备中，尚未公开发布。RC 用于测试与反馈，正式版本以发布页面为准。
IronMLX 是面向 Apple Silicon 的本地模型推理 App，提供 Dashboard 和兼容主流客户端的 HTTP API。

## 系统要求

- Apple Silicon（arm64），macOS 26.4 及以上；不支持 Intel Mac。
- 模型所需内存取决于权重大小、量化、上下文长度和并发量；架构受支持不代表任意设备都能加载。

## 支持的模型架构

| 模型族 | 输入能力 |
| --- | --- |
| Qwen 3.5 Dense；采用相同架构的 Qwen 3.6 / 3.8 Dense | 文本；具备兼容视觉配置与权重时支持图片 |
| Qwen 3.5 / 3.6 MoE | 文本；具备兼容视觉配置与权重时支持图片 |
| Gemma 4 / Gemma 4 Unified | 文本；具备兼容视觉配置与权重时支持图片 |
| GLM-4 MoE Lite | 文本 |
| Llama GQA Dense，包括兼容的 MiniCPM5-1B | 文本 |
| MiniCPM-V 4.6 | 文本、图片；图片路径需要兼容视觉权重 |
| DiffusionGemma | 文本、图片 |

同一模型族的不同版本和量化文件可能存在兼容性差异，下载前请查看[支持模型矩阵](../supported-models.md)中的已验证模型及功能限制。
支持多种量化格式，可根据设备内存选择适合的模型版本；具体范围见该矩阵。

## API 与 Agent 集成

- OpenAI Chat Completions、无状态 Responses，以及 Anthropic Messages 兼容接口，支持 HTTP/SSE 流式输出。
- 支持模型的推理内容输出和工具调用，便于 Agent 完成多轮任务；具体能力取决于模型，工具由客户端执行。
- Structured Outputs 与 JSON Schema 约束，支持范围见 [API 兼容矩阵](../api-compatibility-matrix.md)。
- Hermes Agent、oh-my-pi 的 Provider 配置向导，帮助用户连接本地模型，并提供官方配置指南入口。

## 模型管理与推理优化

- Dashboard 统一模型下载队列，支持 Hugging Face / ModelScope 来源、断点续传、取消和文件完整性校验。
- 加载和卸载模型，设置默认模型、固定常用模型及自动卸载时间，并保存设置。
- 支持并发请求、复用提示词缓存和内存保护；可用优化取决于模型及运行模式。
- 兼容的 Qwen/Gemma 模型可使用 MTP 或辅助模型加速生成，Qwen3.8 支持 DFlash2 文本生成加速。相关配置与组合限制见支持模型矩阵。
- Dashboard 展示运行状态与日志，支持运行时调整日志级别和本地脱敏诊断导出。

## 安装、更新与隐私

RC 与稳定版使用独立的更新通道。模型需要单独下载，安装包不包含模型权重。
默认仅监听本机；可选 LAN 模式使用 HTTPS、API Key 和 Keychain 凭据存储。
诊断导出在本机生成，不自动上传，也不包含提示词或凭据。

## 已知限制

- 图片输入接受 JPEG/PNG/WebP base64，不接受远程图片 URL；不承诺视频或音频生成。
- 模型列表识别 embedding、reranker、ASR 或 TTS 元数据，不代表这些模型可由生成后端加载。
- DiffusionGemma 不支持 KV cache、Prompt Lookup 或 MTP；采样参数限于其独立路径支持的集合。
- 模型支持不代表商业使用或再分发授权，请遵守上游模型条款。
