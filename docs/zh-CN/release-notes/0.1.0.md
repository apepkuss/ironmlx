# IronMLX 0.1.0 候选发布说明

状态：**尚未公开发布**。该版本已具备首个独立产品版本的工程与文档基线，但
public binary 分发仍由 P0-8B 法律材料门禁阻止。

## 主要能力

- 面向 Apple Silicon 的自包含 macOS App 与 Rust/MLX 推理后端；
- OpenAI Chat Completions/Responses 与 Anthropic Messages 兼容 API；
- OpenAI Responses typed output/reasoning、客户端工具和 Structured Outputs；
- Qwen3.8 原生 reasoning 与工具调用；当 checkpoint 和硬件满足支持矩阵时，支持匹配的
  MTP 与独立 DFlash2 文本 actor；
- 多模型生命周期、统一 Dashboard 下载队列、断点续传、不可变快照与完整性校验；
- 连续批处理、分页 KV/前缀缓存、MTP、Prompt Lookup 与内存保护；
- Gemma4、MiniCPM-V 4.6 与 DiffusionGemma 图片输入；
- 本地生成的脱敏诊断信息导出，包含近期故障与运行元数据，不包含 prompt、凭据且不上传网络；
- 默认 loopback，以及带 HTTPS、API Key 和 Keychain 凭据存储的可选 LAN 模式。

## 产品化基线

- App、CLI、`healthz`、Cargo workspace 与发布元数据统一为 `0.1.0`；
- `VERSION` 与自动跳版/一致性校验流程已建立；
- 所有 workspace crate 均设置 `publish = false`；
- App 提供标准 About 面板；
- 生成 macOS arm64 Release 第三方依赖清单、Notices 与许可证原文，并将其纳入
  App/归档；App 菜单提供 `Third-Party Notices…` 入口；
- API 兼容矩阵已明确 v0.1 的 Chat Completions、Responses、Messages 边界，以及
  Qwen3.8/DFlash2 的限制；
- 安装、模型、API、隐私、存储/卸载、排障和 Known Issues 文档已建立；安全漏洞报告、用户支持和贡献政策也已提供中英文说明。

## 发布前仍需完成

- 对已生成的第三方材料完成法律与归属复核；
- 对已生成的 CycloneDX `SBOM.cdx.json` 完成正式复核与批准；
- 完成 Developer ID 签名、公证、stapling 与最低目标机器真实模型验收。

完整限制见 [Known Issues](../known-issues.md)。
