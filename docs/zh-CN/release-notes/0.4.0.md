# IronMLX 0.4.0

[English](../../release-notes/0.4.0.md)

## 自 0.3.0 以来的变更

本版新增菜单栏内置对话、首次使用模型引导、Hugging Face 镜像下载和可取消的模型加载，
并扩展 Agent 工具的 JSON Schema 支持。发布状态和下载见
[GitHub Releases](https://github.com/apepkuss/ironmlx/releases)，准备证据见
[验收记录](0.4.0-validation.md)。

#### 新增功能

- 新增菜单栏对话，支持流式回复、本地历史，以及兼容模型的图片输入和思考控制。
- 为首次使用提供推荐模型下载与加载引导，支持后台进度和模型就绪通知。
- 新增默认关闭的 hf-mirror.com 下载来源；排队、暂停和重启恢复的任务保留所选来源。
- Dashboard 展示模型加载阶段和权重字节，支持取消加载，切换页面和重新打开窗口后保留进度。
- 扩展 JSON Schema 校验和工具参数约束，覆盖 OpenCode、AFT 使用的复杂 schema。

#### 问题修复

- 将对话的每次输出预算限制在上下文的一半以内，为历史保留更多空间；token 估算仍溢出时，按后端剩余额度重试一次。
- 忽略文本 API 不支持的请求字段以改善客户端兼容性，受支持字段继续执行校验。
- 分类返回模型加载错误，DFlash2 启动加载完成前健康检查保持未就绪。
- 切换 App 语言时立即刷新无模型窗口。
- 避免重复注册未变化的本地模型，明确展示生效的调度 profile，不再为普通默认或专用 profile 产生提示。

## 菜单栏对话与首次使用引导

在 IronMLX 菜单栏图标中选择**对话**，即可使用本机模型。对话通过本机 Responses 服务
运行，并在需要时启动服务。窗口支持流式文本、Markdown、代码、数学公式和最近 20 个
本地对话。兼容模型提供图片附件和思考控制。每条消息最多 10 万字符；能看图的模型每条
消息最多接受 4 张图片，每张小于 20 MB。

没有可用对话模型时，若支持的模型目录中有适合当前 Mac 内存的模型，App 会提供推荐。
入门下载流程先尝试 huggingface.co，无法连接时尝试 hf-mirror.com。下载可在后台继续，
App 会请求通知权限以提醒模型就绪。用户也可打开 Dashboard 自行选择模型。对话可以
使用正在运行的 DFlash2 模型，但切换 DFlash2 模型需在 Dashboard 中操作。详见
[用户指南](../user-guide.md)。

对话每次回复的输出预算最多为上下文的一半，即使配置了更大的输出额度。例如，4096-token
上下文最多请求 2048-token 输出，为对话历史保留更多空间。思考和可见答案共用该额度。
最新输入本身超过上下文的一半时，会进一步降低输出预算；仍然放不下时，按完整问答
裁剪较早历史。这只作用于内置对话，不改变后端／API token 上限或保存的模型设置。

只剩最新问题、但后端报告输入加输出预算超过上下文时，对话可以按后端返回的剩余输出
额度重试一次，覆盖初始估算遗漏的 tokenizer／模板开销。这不会修改保存的模型设置；
输入已没有输出空间时仍会报告上下文限制。

## 镜像下载

HuggingFace Tab 新增默认关闭的**使用 hf-mirror 下载**。新搜索和下载使用所选 endpoint；
排队、暂停和重启恢复的任务保留记录的来源。普通 Dashboard 下载失败不会自动切换
endpoint，向第三方镜像发送 HF Token 前需要确认。这与首次使用引导中明确的来源回退
流程不同。详见[模型下载](../user-guide.md)和[隐私说明](../privacy.md)。

## 加载进度、取消与就绪判断

Dashboard 显示加载阶段、权重字节、已用时间和预计剩余时间，关闭面板后在侧边栏显示
进度。切换页面或重新打开 Dashboard 不会丢失进度。取消重新加载会保留当前已加载的
版本；取消切换到 DFlash2 会恢复之前的配置。取消启动时恢复 DFlash2，会以普通模式
重启后端且不加载模型，并保留模型的 DFlash2 设置以供之后使用。

App 管理 API 新增加载任务查询与取消，异步加载返回 `load_id`。推理请求触发加载失败
时，区分配置错误（400）、取消（409）和资源限制（503）。失败模型不会被静默重试，
其错误不附带 `Retry-After`。DFlash2 启动加载未完成时，`/healthz` 返回 503。现有内存
保护保持生效。详见[服务 API](../service-api.md)。

模型注册复用未变化的输入，仅扫描加载或重新扫描需要的模型。状态页和模型设置显示当前
生效的调度 profile；普通默认和专用 profile 不再产生提示。不据此宣称普遍的性能提升。

## Agent schema 与请求兼容性

后端扩展 Draft 2020-12 schema 校验和复杂工具参数约束生成。API profile 与可选语义
仍按文档明确约定，不代表任意 schema 或所有客户端流程均已验收。文本 API 忽略不支持
的请求字段；受支持参数继续执行校验。

开发验证包括官方 SDK 合同、固定版本的 schema 一致性测试，以及使用一个缓存的
Qwen3.8 27B 4-bit 模型进行的真实 OpenCode／AFT 调用。这些结果不代表所有模型或
性能验收。详见[文本与视觉 API](../text-vision-api.md)、[OpenCode 指南](../opencode.md)
和 [schema 证据](../../validation/json-schema-full-acceptance.json)。

[候选包验收记录](0.4.0-validation.md)。
