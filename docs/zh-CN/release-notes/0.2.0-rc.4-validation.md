## 证据与复现

本地证据保留于 `.build/release-readiness/rc4/`：
`evidence.json` 记录所用模型文件、MLX 静态库／metallib 和测试程序的 SHA-256；
同目录保留编译、Clippy 及真模型测试日志。这些本地产物不随 App 分发，
也不会作为模型数据提交。

首次真模型尝试在权重求值时出现 MLX `vector` 运行时错误，尚未开始生成。
将固定版本的 `mlx.metallib` 放到测试程序可发现的位置后通过，无需修改源码。
原始失败日志保留为 `real-model-tests-attempt1.log`；成功日志为
`confidence-verify.log` 与 `ragged-constrained-rows.log`。

在仓库根目录中使用同一现有缓存复现：

```bash
set -e
export MLX_DIR="$PWD/.build/app-bundle/mlx-install"
export MLX_METAL_PATH="$MLX_DIR/lib"
export CARGO_NET_OFFLINE=true
export QWEN36_MOE_MODEL="$HOME/.ironmlx/models/huggingface/mlx-community--Qwen3.6-35B-A3B-4bit/snapshots/38740b847e4cb78f352aba30aa41c76e08e6eb46"
export DFLASH2_MOE_MODEL="$HOME/.ironmlx/models/huggingface/incoai--Qwen3.6-35B-A3B-DFlash2/snapshots/51ef7b6923ad6c14cb1bb41c37a9041446496ab6"
cargo test --locked --release -p ironmlx-runtime \
  --test dflash2_confidence_verify --test dflash2_ragged_constrained_rows --no-run
test ! -e target/release/deps/mlx.metallib
test ! -L target/release/deps/mlx.metallib
ln -s "$MLX_DIR/lib/mlx.metallib" target/release/deps/mlx.metallib
trap 'rm -f target/release/deps/mlx.metallib' EXIT
cargo test --locked --release -p ironmlx-runtime \
  --test dflash2_confidence_verify --test dflash2_ragged_constrained_rows \
  -- --ignored --nocapture --test-threads=1
```
