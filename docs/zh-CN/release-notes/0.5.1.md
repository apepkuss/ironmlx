# IronMLX 0.5.1

[English](../../release-notes/0.5.1.md)

## 相对 0.5.0 的变化

本补丁改进缓存复用和内存使用，修复 Gemma4 批处理及预填充错误处理。
发布状态和下载以 [GitHub Releases](https://github.com/apepkuss/ironmlx/releases) 为准。

<!-- release-summary:stable -->
#### 问题修复

- 修复 Gemma4 分块文本和批量图片请求的前缀复用，并为不使用 position IDs 的模型批量执行冷文本预填充。
- 修复 Gemma4 K3V4 顺序验证时丢失批量投影的问题。
- 预填充批次内存不足时改为逐请求执行，仅拒绝仍无法容纳的请求。

#### 性能与内存

- Dense KV 缓存随请求需要增长，并按增长量计入内存预算。
- 关联前缀缓存条目共享 KV 分段，仅将新增分段写入 SSD，恢复时逐段处理，减少先拼接成连续副本的开销。
- 分页解码注意力改用 split-K，Gemma4 的共享 KV 层直接读取分页解码视图。
- DFlash2 使用缓冲区 pinning 保持权重 GPU 驻留，并覆盖预热生成的权重布局。
<!-- /release-summary -->

## 兼容性与验证

需要 Apple Silicon 和 macOS 26.4 或更高版本。准备的产品版本为 `0.5.1`，
构建号 `13`。本版本不扩展支持模型清单。缓存复用要求模型及执行设置匹配；
缓存未命中时可能需要重新预填充。内存计费不保证所有请求都能在可用内存中执行。

上述条目描述实现行为，不代表普遍的吞吐提升或内存降幅。候选版本验收及其限制
单独记录；最终 tag 身份和公开分发需要维护者批准。参见
[支持模型](../supported-models.md)、[已知限制](../known-issues.md)及
[发布流程](../versioning-and-releases.md)。
