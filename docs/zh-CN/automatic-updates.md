# 自动更新

[English](../automatic-updates.md)

## 检查与安装更新

在启用更新的 RC 或稳定版 App 中，从菜单栏菜单选择“检查更新...”，按提示下载和安装可用版本。
自动检查和下载遵循更新器设置。重启前请保存客户端中的工作；退出 App 会停止后端并中断正在进行的任务。

检查失败不会影响现有 App 的使用，可检查网络后稍后重试。
普通本地源码构建默认关闭更新；更新入口不可用不代表一定有新版本。

## RC 与稳定版通道

RC 和稳定版使用独立的更新通道。已安装的 RC 不会自动切换到稳定版通道。
需要切换时，请在稳定版可用后主动安装稳定版 App，并先阅读对应发布说明。
更新器按全局递增的构建编号判断新旧。`rc.1` 等 RC 后缀是候选版序号，不会重置或决定 App build number。

## 下载与隐私

检查更新会访问项目托管在 GitHub 上的更新源，下载更新会访问该更新源指定的发布文件地址。
更新器在安装前验证更新签名。这些请求不会上传本地模型或推理对话。
网络访问说明见[隐私文档](privacy.md)；手动删除或替换数据前请阅读[数据位置](storage-and-uninstall.md)。

签名密钥、更新源发布及失败恢复见[发布流水线](stable-release-pipeline.md)。
